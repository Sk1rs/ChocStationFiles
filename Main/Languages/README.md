# Языки для SS14 (порт с Dead Space на Sunrise)

Короче. Теперь у каждого пидора на станции есть языки. Ниан пиздит на своём ткачьем - ты видишь
не «капитан мудак», а «ка'ши ра то зи». Корги говорит - у тебя в чате «Гав!». Знаешь язык - видишь
нормальный текст и подпись `(Ткачий)`. Не знаешь - сиди и хлопай глазами.

Работает везде: речь, шёпот, радио, интеркомы, TTS. Не понимающие слышат не голос, а озвученную
тарабарщину или звук языка (лай, мяуканье, щелчки).

Спизжено с **[Dead Space 14](https://github.com/dead-space-server/dead-space-14)** и допилено
под Sunrise. Всё помечено `DS14-Languages`, так что хер потеряешь.

---

## Как юзать в игре

- **L** или кнопка «перевод» сверху → радиалка с языками → тыкаешь нужный. Текущий подписан «(выбран)».
- Выучить новый - **языковой имплант** из протолата (технология «Простейшие языковые импланты», сервис, T2).
- Призраки и админы понимают всё. Зомби - только зомбячий, остальное нахуй забывают.
- Звери без разума не понимают нихуя, пока не накормишь когнизином.

19 языков: общий, ткачий, синта'унати, це'хисс, шелестящий, пузырчатый, вокс-птичий, канилунц,
кошачий, собачий, обезьяний, демонический, дварфийский, двоичный, эве-пишту, эхоглосса,
ваал'хурис, блобий, зомбячий.

## Как перетащить к себе

1. **Скопируй `files/` в корень репы.** Там только новые файлы, ничего твоего не перезапишет.
2. **Пройдись по `patches/code.md`.** 16 файлов, каждый кусок с парой строк вокруг - видно, куда пихать.
   Самое мясо - `ChatSystem.cs`, `RadioSystem.cs`, `TTSSystem.cs`. Не проебись с ними.
3. **Раскидай языки по `patches/entities.md`.** Вставляешь `- type: Language` в `components:`
   нужной сущности. **Смотри на отступ** - где-то компоненты с 2 пробелами, где-то с 4.
   Я на этом уже один раз обосрался и снёс карпам все компоненты. Не повторяй.
4. **Собери в Release** и прогони линтер:
   ```bash
   dotnet build -c Release
   dotnet run --project Content.YAMLLinter -c Release
   ```
   Если линтер орёт про `…Language` - ты вписал язык, которого нет в `languages.yml`.

## Грабли, на которые можно наступить

- **Не Sunrise TTS?** `TTSSystem.Languages.cs` и правки в `TTSSystem.cs` заточены под сунрайзовский TTS.
  Если у тебя Corvax-TTS или вообще без него - выкидывай эти два и допиливай сам, остальное заработает.
- **Названия языков - ключи локали** (`language-moth-name`), а не текст. Новый язык без строки
  в `languages.ftl` = в меню будет висеть голый ключ.
- **Id рас в прототипах строгие.** Нет у тебя вульпканинов - выкинь их из списков, иначе линтер пошлёт нахуй.
- **Меню на `SimpleRadialMenu`** - это ванильный контрол. У DS14 было своё радиальное говно, которого нет в Sunrise.
- **Клавиша L** должна быть свободна. Занята - поменяй в `keybinds.yml` или в настройках управления.

В шапке файлов из Dead Space - их кастомная лицензия с **запретом на публичный хостинг и коммерцию**
(ссылка прямо в заголовке). Для себя/локалки - похуй. Если собираешься поднимать публичный сервер -
почитай, прежде чем тащить.
