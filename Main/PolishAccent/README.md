# Польский акцент (`polish`)

Персонаж пиздит по-русски, а на выходе получается смесь русского с польским.

Это **замена испанского акцента**: старый `spanish` выпилен целиком, вместо него встал `polish`. Работает на общем движке подмены слов, своего кода у механики **нет** (у испанского был - см. п.7).

```
Игрок написал в чат
```

Ничего кроме данных тут нет. Хочешь новое слово - правишь два файла, C# не трогаешь.

## 3. Как устроен словарь

Одно правило - это **две** пары строк. В `.ftl`:

```ftl
accent-polish-words-27 = бля
accent-polish-words-replace-27 = kurwa
```

В прототипе:

```yaml
    accent-polish-words-27: accent-polish-words-replace-27
```

То есть YAML знает только **имена ключей локали**, а не сами слова. Поэтому одна и та же строчка YAML на русском клиенте меняет «бля» → `kurwa`, а на английском `damn it` → `kurwa`. Удобно.

Сейчас в словаре 47 правил, разбитых на блоки:

1. **1–13** - фразы целиком: «я работаю» → `Pracuję`, «я поляк» → `Jestem Polakiem`.
2. **14–27, 32** - мат. Замена жёсткая, один в один: «бля» → `kurwa`, «блять» → `kurwa mać`, «пошел нахуй» → `spierdalaj`, «хуй» → `chuj`, «ебанутый» → `pojebany`, «пьяный» → `najebany`. Рандома нет - одно и то же слово всегда выходит одинаково, чтобы игроки могли выучить.
3. **28–31** - местоимения: «я» → `ja`, «меня» → `mnie`, «мне» → `mi`, «мной» → `mną`.
4. **33–47** - головы отделов и их сленговые сокращения: «кэп» → `kapitan`, «гсб» → `ochrona`, «си» → `inżynier`, «нр» → `naukowiec`, «км» → `kwatermistrz`.

## 4. ⚠️ Порядок правил - это не украшение

Правила применяются **строго сверху вниз**, в порядке записи в YAML.

Поэтому фразы обязаны стоять **выше** коротких слов, которые в них входят. Иначе правило `я → ja` сожрёт местоимение раньше, чем сработает `я работаю → Pracuję`, и на выходе будет «ja работаю» вместо `Pracuję`. Весь смысл потеряется нахуй.

**Правило простое: чем длиннее фраза, тем выше она в списке.**

## 5. Что делает движок, чтобы не обосраться

Стоит знать, иначе будешь удивляться поведению:

- **Границы слова.** Регулярка `(?<![\w'])слово(?![\w'])` - совпадает только целое слово. «бля» внутри «бляшка» не заменится. Апостроф тоже считается частью слова.
- **Регистр подхватывается.** «БЛЯ» → `KURWA`, «Бля» → `Kurwa`. Писать в `.ftl` надо строчными.
- **Одно слово заменяется один раз.** После замены кусок в служебном буфере забивается подчёркиваниями, так что следующее правило туда уже не влезет. Каскадов вида `а → б → в` не будет.
- **Кэш.** Регулярки собираются один раз и кэшируются по id прототипа. Сбрасывается только на hot-reload прототипов - при правке чисто `.ftl` перезапусти сервер.
- **`ReplacementChance`** у `polish` не задан, значит `1.0` - срабатывает всегда. Если захочешь «иногда» - добавь в прототип `replacementChance: 0.5`.
- **`fullReplacements` убивает `wordReplacements`.** Если в прототипе есть первое, второе просто игнорируется. Не мешай их.

## 6. Как добавить слово

1. Открой **оба** `polish.ftl` (`ru-RU` и `en-US`).
2. Добавь пару с новым номером - нумерация сквозная, следующий свободный `48`:
   ```ftl
   accent-polish-words-48 = спасибо
   accent-polish-words-replace-48 = dziękuję
   ```
   В `en-US` - то же самое, но слева английское `thank you`. **Ключ обязан быть в обоих файлах**, иначе на одной локали строка вылезет в чат сырым ключом.
3. Допиши строку в прототип `id: polish`, **в нужное место** по правилу из п.4:
   ```yaml
       accent-polish-words-48: accent-polish-words-replace-48
   ```
4. Проверь в игре: трейт `Польский акцент` в редакторе персонажа, или просто надень сомбреро.

**Чего не делать:**
- не переиспользовать номер;
- не ставить многословную фразу в конец списка;
- не писать замену с заглавной буквы (кроме имён собственных) - движок сам поднимет регистр;
- не забывать `en-US`.

## 7. Хвосты, которые надо подтереть

Механика - это переделанный испанский акцент. После переделки осталось говно, которое желательно убрать **до** пуша:

1. **`PolishAccentComponent.cs` и `PolishAccentSystem.cs` висят в git-индексе, но удалены с диска** (`git status` показывает `RD`). Внутри - до сих пор старый испанский код (класс `SpanishAccentComponent`, вставка `es-` перед `s`, перевёрнутые `¿¡`). Новому акценту C# не нужен вообще. Выкинуть:
   ```bash
   git rm --cached Content.Server/Speech/Components/PolishAccentComponent.cs Content.Server/Speech/EntitySystems/PolishAccentSystem.cs
   ```
   Если оставить как есть - в коммит уедет мёртвый файл с чужим именем класса.

2. **В `Resources/Prototypes/Accents/word_replacements.yml` в конец насрано 124 строки ASCII-арта** (~37 КБ комментариев `#@@@@@...`). Полезной нагрузки там ноль. Удалить перед пушем, иначе ревьюеры на гитхабе будут смотреть на это и плакать.

3. **Сомбреро и пончо** - вещи мексиканские, а дают польский акцент. Технически работает, логически бред. Либо вернуть им отдельный акцент, либо повесить `polish` на что-то польское.

## 8. Если сломалось

| Симптом | Причина |
|---|---|
| В чат летит `accent-polish-words-48` | Ключа нет в `.ftl` текущей локали |
| Слово не заменяется | Опечатка в `.ftl`, или его раньше сожрало правило выше, или не перезапустил сервер после правки локали |
| Заменилось не то | Порядок в YAML - подними длинную фразу выше |
| Заменяется кусок слова | Такого не бывает, регулярка держит границы слова. Значит ты правил не тот акцент |
| Акцента нет совсем | Нет `ReplacementAccentComponent` на сущности - не взят трейт / не надета шмотка |
