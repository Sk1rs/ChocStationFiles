О репозитории About

Данный репозиторий не является билдом игры и не содержит полноценный клиент или сервер SS14.

Здесь находятся:

  • Новые предметы
  • Механики
  • Текстуры и спрайты
  • Звуки
  • YAML-прототипы
  • Entity-файлы
  • Локализация
  • Прочий контент

This repository is not a game build and does not contain a full SS14 client or server.

It includes:

  • New items
  • Mechanics
  • Textures & sprites
  • Sounds
  • YAML prototypes
  • Entity files
  • Localization
  • Other content
Назначение Purpose

Репозиторий используется для:

  • Разработки нового контента
  • Хранения игровых ассетов
  • Тестирования механик
  • Переноса контента между сборками
  • Совместной работы над проектом

The repository is used for:

  • Developing new content
  • Storing game assets
  • Testing mechanics
  • Migrating content between builds
  • Collaborative project work
Важно Important
  • Репозиторий содержит только контентную часть проекта.
  • Для запуска потребуется отдельный билд Space Station 14.
  • Некоторые элементы могут требовать дополнительные зависимости.
  • This repository contains only the content portion of the project.
  • A separate Space Station 14 build is required to run it.
  • Some elements may require additional dependencies.
